# 0053 — 多序列的柱子是一层：分组与堆叠属于图，拐角属于序列

状态：Accepted（2026-11-26 实现，干净房间实测）

## 问题

两件事在同一天被发现，根是同一个：

1. **两个序列都画成 `interval` 时，图上是"一根柱"。** 归一层把每个序列拆成一个 child（ADR 0051 §4），每个 child 各画各的柱，同一个 `x` 上直接叠在一起。G2 的分组（`dodgeX`）与堆叠（`stackY`）都是**一层**的 `transform`，靠层里的分组通道分出并排或上下；一个 child 只带一个序列，那个通道根本不存在，于是既不能并排也不能叠。
2. **折线只有直段。** G2 自带 `style.shape`（`smooth` / `vh` / `hv` / `hvh`），模块一处没写，所以面板上也没有地方说"这条线圆不圆"。

## 决定

1. **全部可见序列都是 `interval`、且至少两个时，折回一层。** 那一层是一个 `interval` child：数据是把各序列的行拼起来（每行写上自己序列的名字，`encode.color` 指向那个字段），`transform` 只有一项——分组取 `dodgeX`，堆叠取 `stackY`。颜色走这一层的 `scale.color`（`domain` = 可见序列名，`range` = 各自面板里选过的颜色）；隐藏仍然是"把那些行拿掉"，与层模式过滤 `data` 是同一条路（ADR 0051 §6）。
2. **混合图不折。** 判据是"全部都是 `interval`"，一条线、一块面积都足以否决：形态按序列分别写在各个 child 的 `type` 上，折成一层就只剩一个 `type`。折不了的时候回到旧的覆盖式 children——不完美，但那是唯一能同时保住两种形态的形状。
3. **分组 / 堆叠是图级的**，与坐标同一层级：右上角第二个 20px 按钮，图标就是当前态（两条并排 / 一条两段），点击切换，缺省分组。它只在能折的时候出现——一条柱没有分组可谈，柱加线的图没有堆叠答案。形态、颜色、拐角仍是序列级的，入口仍在该序列的色块里（ADR 0051 §3、§8 的分工不变）。
4. **拐角是序列级的。** `line` / `area` 的面板里多一行「折角 / 平滑」，平滑写 `style.shape = "smooth"`，折角是不写（直段是 G2 的缺省）。于是两条线可以一条圆一条不圆。`vh` / `hv` / `hvh` 不进面板：那是阶梯语义，与"圆不圆"不是同一个问题。
5. **坐标每次写明，包括 `cartesian`。** `options()` 是拿新 spec 去 patch 旧树，删掉 `coordinate` 节点等于什么都没说，旧坐标留在原地——于是"切回平面直角坐标"曾经一整轮都不生效。现在 `root.coordinate = { type: … }` 无条件写出来。

## 后果

- 柱图里"每序列一个 child"不成立：形状是整层一个，所以不能一半柱一半别的（正是第 2 条）。图例仍然一项一个序列，颜色仍然各记各的。
- 折叠只发生在**可见**序列上：隐藏一个之后剩下的还全是 `interval`，仍然折；隐藏到只剩一个就退回单层单序列，`transform` 不再写，按钮也消失。
- 堆叠 / 分组的选择不随帧重置，与坐标、隐藏、颜色同一条边界：读的人的手势，不上行（ADR 0032 §2、ADR 0051 §7）。
- 并排时同一年的两根柱各占一半，间距由 G2 的 band 标尺算；柱太细是 G2 的事，模块不补最小宽度。
- 平滑只改线形，不改数据点：`smooth` 是 G2 的曲线插值，读的人看到的是同一年同一收入，只是中间那段走曲线。
- 折回一层之后，`scale.color` 的 `domain` 是可见序列名——隐藏一个序列会让 G2 重新分配缺省配色，除非该序列选过颜色（选过的在 `item.color` 里，跟着序列走）。这一条是"颜色属于序列"的代价，接受。

## 与先前的方案

ADR 0051 的模型是"一个序列一个 child"，形态与颜色因此各归各的、可以逐条改。这个模型对折线和点是对的，对柱子漏了一件事：柱子的并排与堆叠是序列**之间**的关系，而"每个序列自己的 child"里没有序列之间的关系。补法不是把模型推翻，而是给它一个特例：**全是柱的时候，他们本来就是一层的，折回去**。判据与代价都写在上面，其余形状仍按 0051 走。
