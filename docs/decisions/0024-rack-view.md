# ADR 0024: rack 的 `view`——同一批行，六种摆法

状态：已定（代码同时落地）
日期：2026-10-31
仓库：fluxen

## 背景

管理屏需要一条说给人听的话：保存被拒时，屏上得有个地方出现一行字、停一会儿、自己走开，
而且不占版面。这个需求的形状是"通知区"，但把它做成一个通知组件是错的方向——真正被复用的
是**行的摆法**，不是"通知"这个用途：首页横幅要的也是同一批东西（一次一条、淡入、换下一条、
能按住），聊天流要的是另一头（全挂着、可滚、跟尾巴）。

所以问题不是"要不要一个通知组件"，而是 rack 现在只会一种摆法：`attrs.scroll: bool`。

同时有一条上位裁定（2026-10-31）：**服务端只送消息，显示多久、什么效果归 UI**。所以帧里不出现
任何时长、任何效果的描述——那些是渲染器的词汇，不是线上协议的一部分。

## 决策

1. **不新增容器类型。** rack 里带不变量的是"槽 → 键控行 → item 模板"这套（行身份、merge、
   位置索引），而下面六条轴全是同一批行的搬法。另起一个走马灯类型等于把行机制抄第二份，两份
   迟早分叉。rack 长出 `attrs.view: RackView`。

2. **六个轴，默认值等于老 rack。** `layout`（adaptive 流／fixed N／exclusive 一行）、
   `direction`（vertical／horizontal）、`enter`（none／fade／translate）、`scroll`
   （none／bar／indicator／arrow）、`play`（newest／rotate，`every` 毫秒）、`pause`
   （off／click／hover）。六个默认值合起来正好是既有行为，所以老帧不写 `view` 时行为一字不变：
   不新增包装节点、不建定时器、不加类名。旧的 `scroll: true` 保留，解释成 `scroll: "bar"`。

3. **槽是真相，view 只决定露出哪几行。** 轮换、隐藏、窗口都不删行：列表里一个不少，历史留得住。
   轮换走完最后一行归 `None`（没人），而不是回到第一行——一条说过的消息不该每隔一段时间自己回来。
   于是"通知放完区域自然空掉"不需要任何删除动作。

4. **进出场都是 CSS 的事，因此没有渲染器之外的时钟。** 独占布局把所有行叠在同一个 grid 格子里，
   当前那行不透明，显隐走 `opacity` 过渡——淡出不需要谁把节点多留一会儿。进场是一次性的
   `animation`。一条实测教训：进场动画若带 `fill-mode: both`，它会把自己那帧的 `opacity: 1`
   永久钉住，压过"非当前行 opacity 0"的规则，表现为所有排队行全都可见——`both` 必须去掉。

5. **时钟在渲染器里，轮换是队列。** `set_interval(every)` 推进索引，走的是行被说出来的顺序：
   第二条在第一條正被读的时候到达，就排在它后面——队列就是队列，"插队"只在一种情况下发生：
   区域是空的（没人正在读）而有没读过的行，那就立刻给第一行没读过的。轮换走完最后一行归
   `None`，不是回到第一行：一条说过的消息不该每隔一段时间自己回来。`pause: click` 把轮换按住，
   `hover` 同理。行被移除（`remove`）时游标归零重来——位置索引会因删除而重编号，指针不该指向
   一个形状已经变了的列表的中间。

6. **方向只有一个旋钮。** 帧里说 `view.direction`，渲染器把它落成 `attrs.horizontal`
   （`use_common_css` 早就在读的字段）。自己再推一个类名的话，`.f.col` 的权重会赢，帧里说什么
   和类名是什么就各说一套。

7. **"跟尾巴"只活在三种条件的交点上**：`scroll: bar` + vertical + adaptive。聊天流的老行为不该
   泄漏到独占轮换的 rack 上。

8. **通知不是类型，是一组值。** 浮动区（`.toast`）+ `layout: exclusive`、`enter: fade`、
   `scroll: none`、`play: rotate`、`pause: click` 就是通知区；横幅同理，只是 `enter: translate`、
   `every` 更长。渲染器里没有"通知"这个物种。

## 未做（明确的欠账）

- `fixed` 的翻页 UI：`indicator` / `arrow` 的点击与页码还没做，`fixed` 现在只能靠索引推进。
- 进场与离场时长还不是参数（都写死 0.35s）；要调就调 CSS。
- 横向的"跟尾巴"没有实现：跟随规则目前只对 vertical + adaptive + bar 生效。
