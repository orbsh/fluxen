# 0051 — 图的图例是画出来的，每个序列各有自己的形态与颜色

状态：Accepted（已实现，2026-11-26）。真浏览器实测：单 mark + `color` 编码展开成每序列一个 child（三个部门各一条，色块取色标的 rgb(23,131,255)/rgb(240,136,77)/rgb(0,201,201)）、图例项点名字隐藏、点色块出面板、面板里选 `line` 后高亮迁移且菜单不关、改色相后色块变 `oklch(0.62 0.21 40)`、坐标按钮 cartesian→theta→polar→cartesian 且画布尺寸稳定；雷达（layers）四张图仍挂载出画（painted 10585/11366/11682），隐藏一条后 11682→11420。示例 `08.g2chart.series.yaml` 与 `00.radar.yaml` 两轮通过。

## 问题

图（`canvas` 指向 `/assets/g2chart/index.js`，ADR 0025）的载荷是 GoG spec。要加的是两件本来就在语法里、但页面上没有入口的事：

- 一个图里不同序列可以用不同的 mark——张三用线、李四用柱，同一根坐标轴——这是 GoG 分层 mark 的日常用法，不是特例；
- 图例上的每一项，是读的人最自然会去点的地方。

在钉住的 `@antv/g2` 5.4.8 上实测了三条（headless chromium 加载仓库里那份 `g2.min.js`）：

- **图例不是 DOM。** 容器里只有一个 `<canvas>`，document 里零个 legend 元素；图例是场景图上的节点，类名可读且稳定：`g.legend-category` > `g.legend-items-group` > `g.items-item.g2-legend-item` > `g.legend-category-item-marker-group`（bbox 8×8）。场景图的类名读得到位置，但那里没有可以挂按钮的元素。
- **点文字隐藏序列是库自带的。** 点 Apple 那格：画布上色像素 92063 → 82784，并发出 `legend:filter {channel:'color', values:['Mango','Orange']}`。
- **一个 `view` 可以带多个 mark，且共享同一个标尺。** 两个 child（interval + line）数据量级差十倍（0–180 与 8–16），y 的 domain 仍是同一个 `[0,180]`，600×400 正常出图。所以"柱线同轴"是纯数据，不需要新机制。

由此看先前拟的右上齿轮：它只有一根轴（整图的 mark），而形态本来就是**每个序列**的属性；齿轮顺带能给的坐标切换（柱↔饼）又是整图的另一根轴，两者挤在一个菜单里会被读成同一层。齿轮取消。

## 决定

1. **图例自绘成 HTML**，G2 的内置图例关掉：`legend: false` 写在**每一次** render 的 spec 上，帧里给的 `legend` 选项不理会。判据不是"能画就行"：canvas 上的图例挂不上按钮、在皮肤下描不出边，而这里的图例本身就是操作入口；两份图例并存时读的人会去点不能点的那一份。
2. **图例项 = 色块 + 名字。** 名字点击 = 该序列在图上显示 / 隐藏；色块点击（指针设备上悬浮也开）= 该序列的选项面板。
3. **选项面板里两件事**：形态（`interval` / `line` / `area` / `point`，GoG 的 mark 词，不是"柱状图/折线图"这类品类名）与颜色（`L` / `C` / `H` 三个滑块各带一个数字输入框，形状与渲染器的 `color` 字段同一份设计，ADR 0052），外加一行**拐角**（`line` / `area` 才有：折角 / 平滑，写 `style.shape`，ADR 0053 §4）。

   "同一份设计"是字面意思，不是"照着画一遍"：三条色条（`L` 黑白、`C` 取当前亮度与色相往上限走、`H` 整圈色轮）在样式表里只有一条规则，挂在 `.color-row[data-term]` 上，读行上的 `--l` / `--c` / `--h`（ADR 0052 §3）。模块画自己的行时给同样的类、同样的属性和同样的三个数，于是两个面板不靠人同步——它们读的是同一条规则。此前模块只照着渲染器旧版画了条灰线，色条落地那天它不会自己长出来。
4. **序列从 spec 里来。** 模块挂载时把载荷归一层：单个 mark 带 `color` 编码的，按该编码的取值展开成 `{type:'view', children:[…]}`，每个序列一个 child（自己的数据切面、自己的定值颜色）；已经是 `children` 的原样用。图例项就是这些 child，一项一个。
5. **每序列的形态就是那个 child 的 `type`**，颜色是这个 child 的 `style.fill` / `style.stroke` 定值。唯一个例外是全都是柱的时候：整层一个 `type`，形态逐条改不了（ADR 0053）。实测：`style:{fill:'#e11d48'}` 画出 225,30,72，`style:{stroke:'#2563eb'}` 画出 37,99,235，同一坐标系同一次 render。
6. **隐藏 = 把那个 child 从 `children` 里拿掉再重绘**，不用 G2 的 filter 交互。柱子折回一层时改为把那些行从数据里拿掉（同样是"拿掉"，只是拿的单位从 child 变成行，ADR 0053 §1）。两条路都能隐藏，但既然序列已经各自成 child，"拿掉"是唯一的事实，filter 是在它之上再造一层"哪些被过滤了"的状态。
7. **不上行。** 形态、颜色、显隐都是读的人的手势，不是数据——与字段同一条边界（ADR 0032 §2）。服务端不知道用户把哪条线切成了柱。
8. **坐标轴是整图的一根轴，它有自己的开关。** 图右上角一个 20px 的按钮，**按钮的脸就是当前坐标的图标**——不是齿轮、不带菜单，点一下切到下一个。列表**只来自** `options.coordinate`，没有缺省的三件套：帧不声明，就只有 spec 自己写的那个坐标，按钮不画。理由是柱图在饼坐标（`theta`）下就是一叠扇形、时间序列在 `polar` 下就是一丛放射线——"读起来像坏了"的画面不该由默认值送上来，要给，帧自己给。帧里 spec 写的那个坐标是起点，不在列表里就排在最前；列表只有一个时不画按钮。两处操作分工写死：**坐标是图级的**（右上角那一个开关），**形态与颜色是序列级的**（图例里每一项自己的面板），不共用入口。

## 代价

- **图例排版归我们**：换行、间距、与绘图区的对齐、resize 之后重排。G2 那份（布局是它自己的 flex 引擎算的）省不回来了。
- **归一层改写了 spec 的形状**：生产者写的"一个 mark"在运行时是 N 个 child。副产物是颜色不再走 `color` 标尺，而是每个 child 的定值——图例的配色也由模块自己记着。
- **颜色面板有两份实现**：wasm 里的 `color` 字段与模块里的 JS。这是模块边界（ADR 0025）的定价，不是疏忽；两份要一起改的时候没有编译器提醒。
- **关掉内置图例，`legend:filter` / `legend:reset` 一起消失**。以后想看"谁被隐藏了"，只有模块自己知道，而它现在不对外。
- **图标没有公认的图形。** `cartesian` / `theta` / `polar` 是抽象概念，三个小 SVG 是设计出来的，不是查来的；认不出来时只能靠 `title` / `aria-label` 补词名，所以按钮必须带悬停文字，不能只有图形。
- **切换坐标是整张图重排**：标尺、绘图区、每个 mark 的映射一起变，不是热更新（与 `options` 挂载期静态那条同一个事实，ADR 0017 §3）。
- **归一只认两种形状，判据是「这一层是不是一个序列」**：颜色通道在一个 child 里**跨多个值** = 层（雷达的 `area` 填充 + `line` 描边，同一批人），每个 child 只带**一个**值 = 序列。层模式下图例只列序列、只允许隐藏（隐藏靠过滤 view 的 `data`），形态与颜色不给——把一层 mark 换掉等于把合成拆散。其余形状（facet、其他 composition、没有颜色通道的多层）仍按「两个 child 就是两个序列」处理，生产者不要以为任意层次都能被理解。
- 只有一个序列时图例也照画：它是唯一的操作入口，去掉就没有地方改形态了。

## 与先前的方案

先前记过一版"右上角小齿轮 + 整图 mark/坐标切换"，没有实现。齿轮取消：整图的 mark 轴没有它该在的位置——形态是每序列的属性，归图例。坐标轴留下，但换了形态：不是齿轮菜单，是一个**显示当前值、点击循环**的开关，位置仍在右上角。
