# 0052 — 颜色字段：一块方片，一个三滑块的悬浮面板

状态：Accepted（已实现，2026-11-26）。真浏览器实测：行内 `oklch(0.62 0.18 250)` + 方片，悬停出面板（3 滑块 / 3 数字框），拖 L 到 0.90 后字面量、方片、数字框一起变，填 H=33 滑块跟随，stage 侧收到 `accent: 0.90 0.18 33`（loom 打包的 triple）。同日补测三条关闭/端点路径：无焦点时 Esc 关、点外部关、点面板内部不关（不冒泡到方片的开关），`H` 拖到 `max` 后仍是 `360`、字面量 `oklch(0.70 0.00 360)`，三条条的 `--bar` 分别是黑白渐变、`oklch(0.70 0.00 360)`→`oklch(0.70 0.40 360)`、13 个色标的色轮；`gate_settings` 13/13、`cargo test --workspace` 全绿。

## 问题

ADR 0048 的 `disc` 是 `oklch` 平面上的一个盘，128×128。用下来的两个结论：

- **太占地方。** 设置页十个颜色令牌一列排下来，盘本身把页面撑掉了半屏；而这一页里颜色最常见的样子是"看一眼现在是什么、偶尔改一下"，不是一直摊着让人点的操作面。
- **第三根轴被钉死了。** 盘面只有两个自由度，亮度只能由页面用 `attrs.light` 写死（ADR 0048 自己把这条记成代价）。于是"把这个令牌调亮一点"不是一次操作，而是改一次页面。

## 决定

1. **改名 `disc` → `color`。** 名字说的是手势（ADR 0049 之后这个仓的惯例：控件之间只差手势），手势不再是盘。**值不变**——仍是 `"<L> <C> <H>"` 三元组，成员校验、宿主的 `oklch()` 合成、落盘全不动（ADR 0048 那条判据继续成立：控件换掉，值不变）。
2. **行内形态**：一块 16px 的圆角方片（填 `oklch(L C H)`），右边是 `oklch(L C H)` 字面量——等宽字，可选中、可复制。高度就是一行文字。
3. **悬浮 / 聚焦时弹出的是包含头部在内的整块面板**：头部就是同一块方片与字面量（不是"头留在原地、菜单从下面长出来"），下面三行 `L` / `C` / `H`，每行 = 滑块 + 数字输入框。滑块动，输入框跟着变；输入框填，滑块跟着走；头部方片与字面量实时跟。这是"整块浮起来"，不是菜单。

   滑块是一条长条，**条自己画出它改变的东西**：`L` 是黑白渐变；`C` 从「当前亮度与色相下的灰（C=0）」到上限 `0.4`；`H` 是整圈色轮，每 30° 一个色标——两端只写两种色相时，插值走 oklab，会从红直接穿到红，跳过中间那一圈。手柄是条内的一颗圆点，不是一道竖杠：条的颜色本身就是信息，竖杠会盖住它正在指示的那个位置。
4. **`attrs.light` 删除。** 亮度是第三根轴，面板放得下三根，所以它不再是页面的常量。`attrs` 只剩 `class` / `selector`。空值时面板从 `0.7 / 0 / 0` 起（灰），第一次改动才写出值。
5. **拖动是连续值，用字段自己的时钟**：`emit`——与 `input` 同一个词、同一套窗口（ADR 0032 §8），缺省 `{debounce: 250}`。一次拖动是一串值，出口一个窗口一次，不是每次 `mouseup` 一个值。
6. **悬浮只对指针成立**，所以点击与聚焦同样打开面板（ADR 0026 的教训：状态不能只活在 `:hover` 里）；`Escape` 与点外部关闭。两条关闭的腿都挂在 window 上（与 `panel` 同一个做法，`components/panel.rs`）：外面的一次点击可以落在任何地方，而 `Escape` 只送到有焦点的元素——悬浮打开的面板什么都不聚焦，监听挂在面板自己身上就永远收不到。面板内部的点击不冒泡到方片的开关，否则拖一次滑块就把面板解了钉，鼠标一离开就关。
7. 写回的精度沿用现在的 `triple()`：`L`、`C` 两位小数，`H` 取整。输入框显示同一精度，但允许中途输入更多位（见代价最后一条）。**`H` 的两端都在**：`360` 保持 `360`，不回折成 `0`——回折会让滑块一拖到末端就跳回起点，而值经过 loom 回来时 `terms_of` 会再折一次，等于跳两遍；只有轮外的值（`400`、`-40`）才 wrap。

## 代价

- **一次改名加一次手势换代**：reflux 的 builder `h.disc(light=…)` 签名要改（`light` 没了，初值走 `source.default`），`examples/{zh,en}/demo_settings.py` 与 `tools/gate_settings.py`（它按角度与半径点盘）一起重写；`DESIGN.md`、`HANDOFF.md`、reflux ADR 0001 §9 三处提到盘的地方都要改。
- **面板比盘大**——但只在悬浮或展开时大，收起时是一行。
- **三个滑块各带一个输入框**，两向同步外加"填到一半"的中间态（`"0."` 不是一个数），这一层状态比盘多，是这一版真正的复杂度所在。
- **字面量要能选中**，所以面板的指针事件只能挂在头部与滑块/输入框上，不能挂在整个面板上——挂上去就把选择吃掉了，而"复制一个能贴进 CSS 的字面量"正是这块方片存在的理由之一。
